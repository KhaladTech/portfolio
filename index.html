About

I'm a cybersecurity graduate specializing in digital forensics and incident response. My work centers on Windows artifact analysis — registry, MFT, USN Journal, Prefetch, and log correlation — to reconstruct how a system was compromised and what an intruder actually did.

I completed a DFIR-focused internship at a government entity, and I learn best by working real cases rather than studying theory in isolation — most of what's below came out of that approach.

Featured project

ForensiQ + EZ Toolkit

Graduation project

An automated DFIR web platform (ForensiQ) paired with a desktop forensics toolkit (EZ Toolkit) that runs Windows artifact analysis end to end — registry, event logs, MFT, and browser history — instead of chaining separate tools by hand.

The desktop toolkit is a Python app that wraps Eric Zimmermann's tool suite in a working interface, handling tool paths and output parsing so the analyst gets straight to the findings.
